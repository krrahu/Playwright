 1.parallel mode 
 - fullyparallel:true
 - by default worker will be 1 if we don't define it , if ther fullyparallel:true & worker is 1 than it will be serial execution not parallel
- by default worker will be always depend on numner of test , if we define worker as 1 but there is 2 test than worker will be alwyas 2 not 1.
- if we define our worker than define it in config file than it take from config  not as per number of test()
- worker will be allocated depend on number of test
- if worker is not define than it take worker based on numner of test ( 1 test 1 worker, 5 test 5 worker...)

 note:- 
-  if there is multiple test but worker is define 1 than it will run test in serial mode eventhough flag is true.
 - if there is only one test but & worker define as 1 than it will run parallel  mode because worker is matching with test.

 
2. serial wise  / sequence wise
- fullyparallel:false
- worker will be always 1 even though we define the worker more than 1
